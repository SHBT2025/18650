# Battery Manager - 电池内阻管理工具

一个简洁高效的电池内阻管理与测试记录工具，支持 PWA，可安装到手机桌面使用。

## 功能特性

### 🔋 电池管理
- 添加/删除电池，支持 3 位 ID 标识（如 001, 002...）
- 自定义电池名称
- 24 种颜色标签自由选择

### 📊 内阻计算
- **计算模式**：输入初始电压 V₀、负载电阻 R、加载电压 V₁，自动计算内阻
- **手动模式**：直接输入内阻值

### 📜 历史记录
- 每个电池保存完整测试历史
- 显示测试时间、模式、内阻值
- 可删除单条历史记录

### 💾 数据管理
- **本地存储**：数据自动保存到浏览器 localStorage
- **导入/导出**：支持 JSON 格式备份和恢复数据

### 📱 PWA 支持
- 可安装到手机桌面（iOS/Android）
- 支持离线使用
- 原生应用体验

## 使用方法

### 添加电池
1. 在顶部输入电池 ID（如 001）
2. 点击 **+ ADD** 按钮添加电池

### 记录测试
1. 点击电池卡片展开测试面板
2. 选择计算模式或手动模式
3. 输入数据后点击 **RECORD**
4. 记录自动保存到历史

### 导入/导出
- 点击 **Export ↓** 导出数据为 JSON 文件
- 点击 **Import ↑** 选择 JSON 文件导入数据

### 安装到手机

**iOS:**
1. 用 Safari 打开应用
2. 点击分享按钮 → 添加到主屏幕

**Android:**
1. 用 Chrome 打开应用
2. 点击安装提示或菜单 → 添加到主屏幕
