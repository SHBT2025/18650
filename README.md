# Battery Manager — 18650 锂电池内阻管理器

一款简洁高效的 Web 应用，帮助你测量、记录和追踪 18650 锂电池的内阻变化。

[打开应用](index.html)

---

## 核心功能

### 电池管理
- 添加任意数量的电池，为每节电池分配唯一的 3 位 ID
- 点击标签可更换颜色（24 种预设颜色）
- 删除电池及其所有测试记录

### 两种测量模式

**计算模式 (CALC)**
输入三个数值，自动计算内阻：
- **V0** — 电池开路电压（空载）
- **R** — 串联电阻（负载电阻）
- **V1** — 加载后电压（带载）

公式：I = V1 / R → R_int = (V0 - V1) / I

**手动模式 (MANUAL)**
直接输入专业仪器测量的内阻值，适合已有测量设备的用户。

### 历史记录
- 为每节电池保存完整的测试历史
- 显示每次测量的详细参数（电压、电流、计算过程）
- 可单独删除某条测试记录

### 颜色标签
24 种预设颜色，点击电池左上角标签快速切换，便于分类管理。

## PWA 安装

本应用支持渐进式 Web 应用（PWA），可安装到桌面或手机主屏幕。

### 桌面端（Chrome/Edge）
1. 打开应用后，浏览器地址栏右侧会显示安装图标
2. 点击图标或在菜单中选择「安装 Battery Manager」
3. 应用将作为独立窗口打开，无浏览器地址栏

### 移动端（iOS/Android）
1. 用 Safari（iOS）或 Chrome（Android）打开应用
2. **iOS**: 点击分享按钮 → 「添加到主屏幕」
3. **Android**: 点击弹出的「安装」横幅，或 Chrome 菜单 → 「安装应用」
4. 应用图标将出现在主屏幕上，可像原生 App 一样使用

### PWA 特性
- :white_check_mark: **离线可用** — Service Worker 缓存，无网络也能访问
- :white_check_mark: **快速启动** — 缓存资源秒开应用
- :white_check_mark: **原生体验** — 全屏运行，无浏览器地址栏
- :white_check_mark: **自动更新** — 后台静默更新，始终使用最新版本

## 移动端使用

### 界面适配
- 专为触控优化的大按钮和输入框
- 适配刘海屏（Safe Area）
- 支持深色模式（跟随系统）
- 横屏模式下自动调整布局

### 触摸操作
- 点击电池卡片上的 **+ Test** 按钮添加测试记录
- 点击左上角标签（#01、#02...）更换颜色
- 点击 **x** 按钮删除电池
- 点击历史记录旁的 **x** 删除单条记录

### 输入技巧
- 数字键盘自动弹出
- 支持粘贴数字
- 自动转换为大写字母

## 使用方法

### 首次使用
1. 直接打开 index.html 即可开始使用
2. 数据自动保存在浏览器本地存储中

### 添加电池
1. 在工具栏输入 3 位 ID（留空则随机生成）
2. 点击 **+ Add**
3. 选择测量模式，输入参数
4. 点击 **Save Test** 保存

### 添加测试
1. 点击电池卡片上的 **+ Test**
2. 选择模式并输入数据
3. 保存测试记录

## 数据导入导出

### 导出数据 (Export)
点击工具栏的 **Export** 按钮，将所有电池数据导出为 JSON 文件：
- 文件名格式：battery-backup-YYYY-MM-DD-HH-mm-ss.json
- 包含版本号和导出时间戳
- 包含所有电池 ID、测试记录和颜色信息

### 导入数据 (Import)
1. 点击工具栏的 **Import** 按钮
2. 选择之前导出的 .json 文件
3. 系统会合并数据：
   - 新增：文件中存在但本地没有的电池
   - 跳过：已存在的电池不会被覆盖

## 内阻参考标准

根据实际经验总结的 18650 锂电池健康状态参考：

| 内阻范围 | 健康状态 | 说明 |
|----------|----------|------|
| < 30 mΩ | 优秀 | 全新或状态极好的电池 |
| 30-50 mΩ | 良好 | 可正常使用 |
| 50-80 mΩ | 一般 | 建议降级使用（如低功耗设备） |
| 80-100 mΩ | 较差 | 容量明显衰减，谨慎使用 |
| > 100 mΩ | 老化 | 建议报废或回收 |
